# IMS Backend - Spring Boot Service

This folder contains the Spring Boot 3 / Java 21 backend service for the **Innovation Management System (IMS)** at the **State University of Zanzibar (SUZA)**.

Please refer to the main [Project README](../README.md) for full system architecture, database design specifications, domain entity catalog, multi-phase roadmap, and API usage details.

---

## Quick Start Commands

### 1. Build project
```bash
./mvnw clean compile
```

### 2. Run unit tests
```bash
./mvnw test
```

### 3. Run application (dev profile)
```bash
./mvnw spring-boot:run
```

---

## Key Endpoints
- **Swagger Documentation**: `http://localhost:8080/swagger-ui.html`
- **OpenAPI JSON**: `http://localhost:8080/v3/api-docs`
